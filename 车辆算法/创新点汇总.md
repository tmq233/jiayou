# 论文创新点汇总

## 1. 自适应 ε_max(s)

定义一个对环境危险度的度量 `d(s)`：

- 危险度 `d(s)` 越大（越安全）→ `ε_max(s)` 越大 → `λ0(s) = 2·ε_max(s)/g_max` 越大 → RL 越自由；
- 反过来 `d(s)` 越小（越危险）→ `ε_max(s)` 越小 → 策略被逼得越贴近专家 → 越安全。

## 2. 偏离惩罚改用加权范数

现在偏离惩罚用的是普通欧氏距离 `‖π − π_expert‖²`，等于把"速度大小偏离"和"朝向偏离"一视同仁。但直觉上，靠近障碍物时"朝着障碍物拐"比"开快一点"危险得多。

可以换成加权范数 `‖π − π_expert‖²_W(s)`，让 `W(s)` 随障碍物方向变化。

## 3. 危险度度量

用更聪明的危险度 `d(s)`——time-to-collision（TTC）。你第一步大概率会用"到最近障碍物距离 `d_min`"，但 `TTC = 距离 / 接近速度`，能更早捕捉"虽然还远但正在快速逼近"的危险，对动态人群尤其有效。

## 4. 奖励函数构成优化

把奖励函数里的安全项，从"离障碍物 0.5 米才突然扣分的硬门槛"，升级成与信任域共用同一个连续危险度 `d(s)` 的光滑惩罚——危险越近罚得越狠、越远越平滑，再顺手加进平滑与行人意识两个质量项。

## 5. 测评环境的复杂性

动态人群密度扫描、狭窄通道、移动目标点、BARN 标准基准。原论文场景偏单一，换更难的场景，可以搭建更加复杂的仿真环境来进行实验。

# 形式化笔记

> 统一约定：`d(s)` 命名为**安全裕度**，**d(s) 越大越安全**。

## 安全裕度 d(s) 的定义（当前公式）

```
d(s) = d_min(s) − v_close(s)·T_h − v(s)² / (2·a_max)
```

逐项解析：

| 项 | 含义 |
|----|------|
| `d_min(s)` | 当前到最近障碍物距离（LiDAR 最近读数 / costmap 距离） |
| `v_close(s)·T_h` | 反应时间 T_h 内还会冲出去的距离；v_close 为相对接近速度 |
| `v(s)²/(2·a_max)` | 全力刹车后还需滑行的距离；a_max 为最大减速度 |

利害分析：

- 优点：把"接近速度"揉进安全度，能提前捕捉"正在逼近"的危险（行人迎面快走时 d 立刻变小）；停在墙边 v=0 时退化为 d_min，不会像 TTC 那样分母趋 0 爆炸；全程加减乘除，有界、光滑、算得快。
- 缺点：需额外估计 v_close（对 LiDAR 序列差分/滤波得到）；新增 a_max、T_h 两个超参；暂不区分"旁边静止的墙"与"正前方墙"（方向信息后续交给各向异性 W(s) 处理）。

> 备注：朴素的 `d_min`（运动盲区）与 `TTC`（速度趋 0 时爆炸）都不直接用，上式正是针对这两个毛病构造的。

## 安全半径 ε_max(s) 的定义（当前公式）

```
ε_max(s) = ε_min + (ε_open − ε_min)·(1 − e^(−d⁺(s)/d0))，其中 d⁺(s) = max(d(s), 0)
```

逐项解析：

| 项 | 含义 |
|----|------|
| `ε_min` | 下界：最危险时的最小偏离半径 |
| `ε_open` | 上界：最开阔时的最大偏离半径 |
| `d0` | 特征距离：半径随安全余量涨多快（大=慢/保守，小=快/放开） |
| `(1 − e^(−d⁺/d0))` | 饱和增长因子 ∈ [0,1]：d⁺=0 时为 0，d⁺→∞ 时趋 1 |

性质：单调递增、有界 ∈ [ε_min, ε_open]、d≤0 时压到 ε_min、d→∞ 时趋 ε_open、参数仅 3 个。

保证链：`λ0(s) = 2·ε_max(s)/g_max` → `λ̃(s) = min(λ, λ0(s))` → `‖π(s) − π_expert(s)‖ ≤ ε_max(s)`。

利害：

- 优点：有界、单调、几乎处处光滑、参数少、每项有物理含义。
- 注意：① `d⁺=max(d,0)` 在 d=0 有导数小拐点（无害）；② ε_min 取 0（危险时完全听专家）还是正数（留一丝 RL 自由）是安全/性能权衡，定值留实验阶段；③ ε_open ≤ a_max（动作空间物理上限）。

## 各向异性信任域加权矩阵 W(s)（当前公式）

设偏离向量 `e = π(s) − π_expert(s) = (e_v, e_ω)`（e_v 线速度偏离、e_ω 角速度偏离）。加权范数：

```
‖e‖²_W(s) = eᵀW(s)e = w_v·e_v² + w_ω·e_ω²

w_v(s) = 1
w_ω(s) = 1 + κ·e^(−d_f(s)/d_f0)
```

逐项解析：

| 项 | 含义 |
|----|------|
| `w_v = 1` | 线速度偏离基准权重（速度维由 ε_max(s) 兜底） |
| `w_ω = 1 + κ·e^(−d_f/d_f0)` | 角速度偏离权重：κ 为最大额外权重，d_f0 为特征前方距离 |
| `d_f(s)` | 前方扇区安全余量：朝向 ±θ_f 内最近障碍物距离（无则 +∞） |

作用：前方有障碍（d_f→0）时 w_ω→1+κ，转向偏离被重罚；前方开阔（d_f→∞）时 w_ω→1，退回各向同性。即把信任域从"圆"捏成"椭圆"——在总预算 ε_max(s) 内，把偏离从危险转向轴重新分配到安全速度轴。

保证不变：静止点 `λ̃∇ₐQ = 2W(s)e` → `e = (λ̃/2)W⁻¹∇ₐQ`，因 `λ_min(W)=min(w_v,w_ω)=1`，故 `‖e‖ ≤ (λ̃/2)L ≤ ε_max(s)` 原样成立。

利害：

- 优点：仅新增 κ、d_f0、θ_f 三个参数；故事清晰（圆→椭圆）；Theorem 1 保留；按扇区查 LiDAR 极便宜。
- 注意：当前 w_v 恒 1（"前方开快"未单独加重，靠 ε_max(s) 整体收紧兜底），后续可扩展。

## 逐点版定理（状态依赖的偏离界）

**定理**：假设 ① critic 关于动作 L-Lipschitz（‖∇ₐQ(s,a)‖ ≤ L）；② 梯度惩罚压 L ≤ g_max；③ W(s) 对角且 λ_min(W(s)) ≥ 1；④ λ̃(s)=min(λ, λ0(s))，λ0(s)=2·ε_max(s)/g_max。则对目标

```
J(ϕ) = E_s[ λ̃(s)·Q(s,π(s)) − ‖π(s) − π_expert(s)‖²_W(s) ]
```

的任意静止点 π*，有 `‖π*(s) − π_expert(s)‖ ≤ ε_max(s)`，∀s。

**证明（四步）**：

1. 静止点条件：对 π 求导令零，`λ̃(s)∇ₐQ = 2W(s)e`，得 `e = (λ̃(s)/2)W(s)⁻¹∇ₐQ`（e = π − π_expert）。
2. 取范数：`‖e‖ ≤ (λ̃(s)/2)·‖W(s)⁻¹‖·‖∇ₐQ‖`。
3. `‖W⁻¹‖ = 1/λ_min(W) = 1`（w_v=1, w_ω≥1），且 `‖∇ₐQ‖ ≤ L ≤ g_max` → `‖e‖ ≤ (λ̃(s)/2)g_max`。
4. `λ̃(s) ≤ λ0(s) = 2ε_max(s)/g_max` → `‖e‖ ≤ ε_max(s)`。∎

**结论**：原论文 Theorem 1 是本定理 ε_max(s)≡常数 的特例。L ≤ g_max 全局成立，状态依赖仅经 λ̃(s) 进入，无需逐状态重推 Lipschitz 界；危险处 ε_max(s)→ε_min（锁紧），开阔处 →ε_open（放开）。

**备注（需在论文中声明）**：静止点条件的逐点成立隐含"策略参数化表达能力足够"的设定，与原论文 [23] 推导一致。

## 奖励函数的光滑安全项（当前公式）

将原论文硬门槛安全项 `R_c = min(d_collision − 0.5, 0)` 替换为与信任域共用同一 d(s) 的光滑惩罚：

```
R_safety(s) = −c_s · σ(−d(s)/d_s0) = −c_s / (1 + e^(d(s)/d_s0))
```

逐项解析：

| 项 | 含义 |
|----|------|
| `d(s)` | 与信任域共用的安全裕度（RSS 式，允许为负） |
| `c_s` | 最大惩罚强度（d → −∞ 时扣分上限） |
| `d_s0` | 特征距离：惩罚随安全余量上升多快 |

性质：光滑（处处可导，无原 min 的硬拐点）、有界 ∈ (−c_s, 0)（d 很负也不爆炸）、单调（越安全罚越轻）。

利害：

- 优点：与信任域共用 d(s)，一次计算两处使用（奖励罚 + 信任域勒），叙事统一；光滑有界训练稳；符合直觉。
- 注意：新增 c_s、d_s0 两个超参；"阈值对应的惩罚强度"需重新标定，定值留实验阶段。
